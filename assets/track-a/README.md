# Track A 샘플 데이터

## sample-report.pdf

- **출처**: 한국은행 2026년 2월 경제전망보고서 (Indigo Book)
- **용량**: 약 8.6MB
- **언어**: 한국어
- **라이선스**: 공공기관 발간물 (교육 목적 사용 가능)

### 포함된 엣지 케이스

| 엣지 케이스 | 위치 (예시) | 테스트할 모듈 |
|------------|-----------|-------------|
| 숫자 테이블 (행/열) | 경제성장·물가·고용 전망 표 | 모듈 1: PDF 테이블 파싱 |
| 차트/그래프 이미지 | GDP 추이, 소비자물가 추이 그래프 | 모듈 2: PDF 이미지/차트 추출 |
| 전문 약어 | GDP, CPI, 경상수지 등 | 모듈 3: Hybrid Search |
| 범위 한정 주제 | 경제 전망이라는 명확한 스코프 | 모듈 4: 환각 방지 |

### 예시 질문

```
[테이블]  "2026년 GDP 성장률 전망치는 몇 퍼센트인가?" → p.7 표, 정답: 2.0%
[테이블]  "2026년 소비자물가 상승률이 더 높은 반기는?" → p.48 표, 정답: 하반기(2.2%)
[차트]    "GDP 추이 그래프에서 성장률이 가장 낮았던 시점은?" → p.36~37 그래프
[키워드]  "경상수지 전망 차트에서 흑자 규모의 추세를 설명해줘" → 2024년 1,000억달러 → 2026년 1,700억달러로 흑자 확대 추세
[키워드]  "GDP가 언급된 맥락을 요약해줘" → 보고서 전반에 빈출
[환각]    "이 보고서에서 미국 연준 의장의 구체적 발언은?" → 발언 인용 없음
[환각]    "2030년 한국 경제 전망은?" → 2027년까지만 수록
```

> `test_questions.json`에 위 질문들이 포함되어 있습니다. PDF를 직접 열어 확인한 뒤, 본인의 테스트 데이터에 맞게 질문과 정답을 조정하세요.
