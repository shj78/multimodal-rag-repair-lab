| 질문 | Track A 선택 | Track B 선택 |

## 3. 코드베이스 인수인계 문서 (필수)

새 페어가 본인의 코드를 읽고 **바로 실행·디버깅**할 수 있도록 아래 6개 항목을 문서로 작성합니다. 형식은 자유이며, 간결할수록 좋습니다.

- [ ] **서버 실행 명령 한 줄** (예: `pipenv run uvicorn app.main:app --reload`)
- [ ] **`.env` 필수 키 목록** (어떤 키가 필요하고, 어디서 발급받는지)
- [ ] **현재 임베딩 모델명 / 차원수 / 채팅 모델명** (예: `nomic-embed-text` / 768d / `llama3.1`)
- [ ] **Supabase 테이블 스키마** (차원수가 임베딩 모델과 일치하는지 포함)
- [ ] **알려진 버그 또는 주의사항** 1개 이상
- [ ] **(스프린트 3 (멀티모달) 선택 시)** Whisper 모델 크기 / 비전 모델명

## 4. 테스트 데이터 준비

엣지 케이스를 재현하려면 **적절한 테스트 데이터**가 필요합니다. Prework 단계에서 확보하세요.

### Track A

**테이블과 이미지/차트가 포함된 한국어 PDF**를 1개 이상 준비합니다.

- 예시: 기업 연간 보고서, 정부 통계 보고서, 재무제표가 포함된 IR 자료 등
- 텍스트만 있는 단순 PDF로는 테이블 파싱, 이미지 추출 엣지 케이스를 재현할 수 없습니다

> **샘플 제공**: [`assets/track-a/sample-report.pdf`](../../assets/track-a/)에 한국은행 경제전망보고서가 포함되어 있습니다. 예시 질문셋(`test_questions.json`)도 함께 제공됩니다. 자세한 내용은 [`assets/track-a/README.md`](../../assets/track-a/README.md)를 참고하세요.

### Track B

**화면에 슬라이드·코드·자막이 표시되는 한국어 영상**을 1개 이상 준비합니다.

- 예시: 기술 발표 영상, 프로그래밍 강의, 슬라이드가 포함된 세미나 영상 등
- 순수 음성만 있는 파일로는 화면 정보 추출 모듈을 테스트할 수 없습니다

> **샘플 제공**: [`assets/track-b/sample-video.mp4`](../../assets/track-b/)에 한국어 프로그래밍 강의 영상이 포함되어 있습니다. 예시 질문셋(`test_questions.json`)도 함께 제공됩니다. 자세한 내용은 [`assets/track-b/README.md`](../../assets/track-b/README.md)를 참고하세요.
