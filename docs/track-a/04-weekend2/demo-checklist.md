# Track A: 데모 체크리스트

## 데모 필수 시나리오

완주 스토리 모듈을 포함하여 **2개 이상**의 시나리오를 Before/After로 시연합니다.

| # | 시나리오 | Before | After | 해당 모듈 |
|---|---------|--------|-------|-----------|
| 1 | 테이블 수치 질문 | 깨진 텍스트로 오답 | 마크다운 파싱으로 정답 | 모듈 1 |
| 2 | 이미지/차트 질문 | 완전 실패 (무응답) | Vision 설명으로 관련 답변 | 모듈 2 |
| 3 | 키워드 정확 일치 | 벡터 검색에서 누락 | Hybrid Search로 검색 성공 | 모듈 3 |
| 4 | 문서에 없는 질문 | 환각 답변 생성 | 적절한 거부 응답 | 모듈 4 |

> 본인이 선택한 완주 스토리 모듈의 시나리오는 **반드시 포함**해야 합니다.

---

## 데모 영상 구성 (3~5분)

### 구성 예시

1. **(30초)** 프로젝트 소개 + 선택한 모듈 설명
2. **(1~2분)** Before 상태에서 엣지 케이스 재현
   - 실제 시스템에 질문을 던져 실패를 보여줌
3. **(1~2분)** After 상태에서 동일 질문으로 성공 시연
   - 개선된 결과를 보여줌
4. **(30초)** 핵심 지표 Before/After 비교 요약
5. **(선택)** "이 모듈에서 가장 어려웠던 점" 한 마디

---

## 데모 영상 제출 방법

1. 데모 영상을 **Google Drive에 업로드**
2. 파일 우클릭 → **"공유"** → **"일반 액세스"**를 **"링크가 있는 모든 사용자"**로 변경
3. **"뷰어"** 권한이 설정되었는지 확인
4. **링크 복사** → PR 본문의 "데모 영상" 항목에 기재

> GitHub에 100MB 이상 파일은 업로드할 수 없으므로 Google Drive를 사용합니다.
