## 실험 방법론

### 변수 격리

한 번에 하나의 변수만 변경하고 결과를 측정합니다.

```
실험 1: VLM 프레임 분석 적용 → 화면 정보 질문 성공률 측정
실험 2: STT 후처리 숫자 정규화 적용 → 불일치 검색 성공률 측정
(두 변경을 동시에 하지 않음)
```

### 반복 측정

자동 지표는 LLM 비결정성으로 매번 달라질 수 있습니다. 동일 질문셋으로 **3회 이내 반복**하여 평균값을 사용합니다.

### 실패 실험도 기록

역효과가 발생한 실험이야말로 가장 중요한 학습입니다. upgrade-report에 **실패 실험 1건 이상**을 포함하세요.
