# Track B: Upgrade Report

---

## 1. 선택한 모듈과 이유

- **완주 스토리 모듈**: Track 2 — 비전 모델·프롬프트 개선
- **추가 모듈**: Track 3 (시멘틱 청킹 / full 영상 임베딩), Track 4 (pitch·speaker 메타데이터)
- **선택 이유**:
  - Sprint 3 멀티모달 파이프라인은 전사·프레임·청킹·retrieval을 한 번에 묶어 끝냈을 뿐, 각 레이어의 병목을 분리해 검증한 적이 없었다. 그 결과 "영화 토크쇼 도메인" 테스트 데이터에서 세 종류의 실패가 동시에 관찰된다: ① 포스터·출연자 외형 등 **프레임 전용 질문**에 "확인 불가"로 회피, ② 한 토픽이 **2~3분 연속으로 전개**되는 구간에서 고정 30s/5s 청킹이 정답 발언을 쪼개 top_k 밖으로 밀어냄, ③ 같은 영화를 여러 구간에서 언급해도 **어느 화자가·어떤 감정 상태에서** 한 발언인지 retrieval이 구분 못함.
  - 세 실패는 각각 **비전 / 청킹 / 메타데이터** 레이어의 문제라서, 한 트랙씩 변수를 고립해 **Before/After 차이가 선명하게 나오도록** 질문셋(V1~3, C1~4, E1~4 + 환각 테스트 H1)을 설계했다. 완주 스토리인 Track 2는 증거가 가장 분명하고(프롬프트 교체 실험에서 0/3 → 2/3), 데모 재현이 쉽다.

---

## 2. 구현 실험

### 실험 1 (Track 2 — 비전 프롬프트 교체)

- **가설**: baseline(gpt-5.4) 실패의 원인은 모델 크기가 아니라 프롬프트가 "포스터 텍스트·인물 외형"을 추출 대상으로 안내하지 않은 것.
- **변경 내용**:
  - Before: `v5-code` (프로그래밍 강의용 범용 프롬프트) + gpt-5.4
  - After: `v6-talkshow-visual` (포스터·인물·화면텍스트·구도 4섹션) + gpt-5.4 (모델 고정)
- **결과**:
  - Before 0/3 — V1·V2·V3 모두 "제공된 영상/전사에서 확인되지 않습니다"
  - After 2/3 — V1 펄프픽션(포스터 텍스트 인식), V2 "2명"(선글라스 포함) 정답. V3는 여전히 "확인 불가"
  - V3 실패는 프레임 설명에 레보스키 포스터 관련 서술 자체가 **없음**(A유형) — 프롬프트 문제가 아니라 샘플링 주기(`frames_per_minute=1`) 또는 월드컵 대진표 화면에서 개별 포스터가 너무 작아 식별 불가.
- **결론 및 다음 액션**: 병목은 모델이 아니라 프롬프트였음이 확정. V3는 샘플링 레이어 개선(frames_per_minute 상향) 또는 대진표 구간 집중 캡처로 별도 공략.

### 실험 2 (Track 2 — 모델 다운그레이드, 역효과 사례)

- **가설**: v6 프롬프트가 정보 요구를 명확히 하므로, gpt-4o로 내려도 비용 1/3~1/5 절감하면서 2/3 통과율을 유지 가능할 것.
- **변경 내용**:
  - Before: gpt-5.4 + v6 (실험 1 After)
  - After: gpt-4o + v6 (프롬프트만 유지, 모델만 교체)
- **결과**:
  - 통과율 2/3 → **1/3 후퇴**. V2는 유지(속성 카운트에 충분), V1은 **"우나기 (1999)"로 확신 있게 오답** — baseline의 "확인 불가"보다 위험한 새 failure mode.
  - `_VISION_CONCURRENCY=4`로 호출 시 OpenAI TPM 한도 초과 — gpt-4o는 rate limit 쿼터가 더 빠듯.
- **결론 및 다음 액션**: gpt-4o는 속성 카운트에는 충분하지만 **아이코닉 이미지 식별·선명 타이포그래피 읽기**는 불안정. 기본은 gpt-5.4 유지, 비용 민감 경로에만 gpt-4o fallback을 두는 중도안 채택. 또한 QA 프롬프트에 "retrieval에 여러 후보가 섞여 있을 때 결정적 근거 없으면 거부" 조항을 강화해 V1형 환각을 막을 필요가 있음.

### 실험 3 (Track 3 — 시멘틱 청킹 도입)

- **가설**: 고정 30s/5s 청킹이 한 토픽이 2~3분 연속으로 전개되는 구간을 최대 6조각으로 쪼개, top_k=3이 주제의 일부만 복원한다. 시멘틱 청킹으로 토픽 경계를 유지하면 C1("선정 이유 + 감독 리스트")·C4("팬 문화 3분") 개선.
- **변경 내용**:
  - Before: 고정 30s/5s 청킹, v6-talkshow-visual 프롬프트
  - After: **시멘틱 청킹** + v8-talkshow-rag
  - *v6→v8 전환은 시멘틱 청킹 도입 시 `combine_multimodal_context`가 청크당 프레임 설명을 원문 그대로 이어 붙여 `text-embedding-3-small` 상한(8,191 tokens)이 초과됐기 때문. v8은 2섹션·3문장 이내로 프레임당 출력을 축소해 한도 안으로 들어옴. 레이어별로 독립 설계해도 embedding 조립 공통 레이어에서 곱셈으로 누적될 수 있다는 교훈.*
- **결과**:
  - C1 ⚠️→✅ **개선** — 선정 이유([24s])와 감독 3명 리스트([36s])가 한 덩어리로 retrieve. baseline에서 분절됐던 두 발언이 시멘틱 경계 안에 묶임.
  - C2 ❓→⚠️ 부분 통과 — 인맥 자랑 복원, 두 번째 포인트는 gold 재검토 필요.
  - C3 ✅→⚠️ **후퇴** — 청크 수 증가로 노이즈(우나기·카게무샤) 청크가 top_k=3 안으로 유입. 정답 청크 밀도 저하.
  - C4 ⚠️→⚠️ 유지 — "포스터·티셔츠 팬 문화" 구간이 여전히 top_k 밖.
- **결론 및 다음 액션**: C1은 가설대로 시멘틱 청킹 효과 확인. C3 후퇴는 top_k=3이 청크 수 증가를 따라가지 못한 것 — top_k 상향으로 해결 가능성. C4는 3분 gold 구간이 하나의 청크로 묶였는지 `chunk_index` 로그로 직접 확인 필요. v8 축소로 V2(인물 외형) 퇴행 가능성이 있어 격리 재검증 필요.

### 실험 4 (Track 4 — speaker 메타데이터 추가)

- **가설**: 같은 영화가 여러 구간에서 언급되지만 화자·감정 상태로 구분되는 질문(E1~E3)은 메타 없이 풀 수 없다. 먼저 **화자 축(`speaker_id`)만** 투입해 효과를 분리 측정한다. 청크 `context_text`에 `(화자)` 접두어, 문서 메타 `speakers`를 HyDE/rerank 프롬프트(v1 → v2-speaker)에 주입.
- **변경 내용**:
  - Before (Track 4 baseline): gpt-4o + v8-talkshow-rag + v3-cot + full 영상, 메타데이터 없음. **통과율 1/3** (E1 ✅ / E2 ⚠️ 부분 / E3 ✗)
  - After (Step 2): 동일 조건에 `speaker_id`(청크) + `speakers`(문서) 메타 주입 + HyDE/rerank v2-speaker
- **결과** — 판정 분포는 동일(1/1/1)하지만 내용이 축별로 분리:
  - E1 ✅→✅ **유지 (근거 강화)** — "노인을 위한 나라가 없다" 답에 [37:54] "저는 우승할 만하다고 생각합니다"가 **허키 발언으로 결속**. 영화 제목 유형은 메타 없이도 풀리지만 근거 주체가 견고해짐.
  - E2 ⚠️→⚠️ **변형 (수↑ / 인물↓)** — baseline은 "민경 1인"(인물 특정 O, 수 부족), Step 2는 "2명이 지지"(수 정확, **인물명 미특정**). 실패 원인이 retrieval 누락에서 답변 정책으로 이동.
  - E3 ✗→✗ **유지 (격앙 발언만 교체)** — baseline "메인스트림" 발언자 추정, Step 2 "택시 드라이버를 왜 탈락시켜" 발언자로 **후보만 교체, 화자 역전은 동일**. gold(김민경)에 여전히 도달 못함.
- **결론 및 다음 액션**: speaker 메타 **축별 효과 분리 검증 성공**. (a) 화자 축은 *근거 발언 주체 결속*에 효과(E1), (b) 감정 축 필요한 질문(E2 "확신 어조" / E3 "가장 격앙")은 `speaker_id`만으론 미해결 — **병목은 감정 축(pitch)이지 화자 축이 아님**이 확정. Step 3에서 `pitch_mean`·`pitch_std`·`speech_rate`를 추가 투입하고 rerank 프롬프트에 "확신/격앙 어조 판단은 pitch·speech_rate로" 지시를 넣어 E2·E3 회복 여부 측정. 동시에 context_text `(화자)` 접두어가 retrieval/답변 경로에 실제 노출되는지(E2/E3 인물명 미특정 원인) `sources[]` 로그로 분리 확인 필요.

> 실험 2, 3, 4 모두 가설이 완전히 맞지 않은 사례를 포함한다. 실험 2는 모델 다운그레이드 가설을 반증(확신 있는 오답 failure mode), 실험 3은 "변수 독립" 가정이 embedding 공통 레이어에서 깨진다는 것을 드러냄(embedding 한도 곱셈 → v8 축소 조치), 실험 4는 "메타 한 축이면 충분" 가설을 반증(화자/감정 축 분리 필요). 각각 다음 단계 설계 방향을 바꿨다.

### 스프린트 회고 — 남은 미해결 문제와 개인 후속 작업

이번 스프린트에서 **끝맺지 못한 문제**를 정리하고, 스프린트 종료 후 개인 후속 작업으로 이어간다.

| 미해결 문제 | 현 상태 | 개인 후속 방향 |
| ----------- | ------- | --------------- |
| E2 "확신 어조" 판단 / 인물명 복원 | Step 2에서 수는 맞추되 인물 특정 실패. 감정 축 부재가 병목 | pitch 메타(`pitch_mean`·`pitch_std`) 주입 후 rerank 재측정 |
| E3 격앙 주체 역전 (김민경 → 허키 추정으로 뒤집힘) | speaker 메타만으론 회복 불가. 격앙 후보만 교체되는 failure mode 지속 | pitch + `speech_rate` 조합으로 "격앙" 정의를 신호 기반으로 재구성 |
| V3 포스터 A유형 (레보스키 미캡처) | gpt-5.4/gpt-4o 모두 실패 — 모델 크기 무관 | 프레임 샘플링 주기 상향 또는 대진표 구간 집중 캡처 (별 트랙) |
| C3 full 영상 노이즈 유입 / C4 팬 문화 누락 | retrieval 밀도 저하 | top_k 상향·시멘틱 청킹 본격 도입 후 재측정 |

**스프린트 결론**: Track 2(비전 프롬프트)·Track 3 일부(C1 개선)는 이번 스프린트에서 가시적 진전을 얻었고, Track 4의 **축별 효과 분리**까지 검증했다. 다만 Track 4가 원 설계(`speaker_id` + pitch 조합)의 절반(화자 축)까지만 도달한 상태로 스프린트가 종료되었다. 남은 **감정 축(pitch)** 투입은 개인 후속 작업으로 회복 여부를 확인하는 것으로 이번 스프린트 회고를 마친다. pitch 메타가 가설대로 작동하면 Track 4는 완결될 예정이며, 작동하지 않는다면 "격앙" 정의 자체가 신호(pitch)보다 의미(발화 내용)에 더 의존한다는 새 학습이 된다.
