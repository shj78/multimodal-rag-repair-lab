## 📹 Track 2 — 비전 모델 & 프롬프트 검증

**검증 논리**: 전사만으로는 답할 수 없고, **프레임 분석**이 있어야 정답 가능한 질문이어야 한다. 비전 모델/프롬프트 교체 전후로 `retrieval_precision`과 `answer_relevance` 차이가 선명하게 나오는 유형.

| # | 질문 | gold_answer 힌트 | 왜 이 트랙인가 |
| --- | --- | --- | --- |
| V1 | 여자가 담배를 들고 엎드려있는 영화 포스터의 제목은 뭐야? | 펄프픽션 (우마 서먼이 침대에 엎드려 담배를 든 아이코닉 포스터) | 전사는 영화 제목만 언급할 뿐, 포스터 내부의 인물 포즈·소품(담배·엎드림)은 프레임에만 존재. baseline(gpt-5.4) 실제 테스트에서 "확인되지 않는다"로 실패 확인. Track 2 개선(프롬프트 개선) 전후 차이가 선명하게 나올 검증 질문 |
| V2 | 3명의 출연자 중 안경을 착용하고 있는 출연자는 총 몇명이야? | 2명 (일반 안경 착용자 1명 + 선글라스 착용자 1명; 국어 관점에서 선글라스도 "색안경"으로 안경 하위 범주) | 잘린 영상 전사(21~60분)에 "안경" 단어가 한 번도 등장하지 않음 → 완전한 vision-only 질문. 출연자 외형은 프레임에만 존재. baseline(gpt-5.4)에서 "확인되지 않는다"로 실패 확인 |
| V3 | 수염이 난 남성이 주황색 선글라스를 끼고 있는 얼굴의 포스터의 영화 제목은 뭐야? | 위대한 레보스키 (The Big Lebowski) — 제프 브리지스가 수염과 주황색 렌즈 선글라스를 쓴 아이코닉 포스터 | 전사에 "레보스키", "선글라스", "수염", "주황" 모두 0회 → 완전한 vision-only 질문. 월드컵 대진표에는 등장하지만 대결에서 직접 언급되지 않는 영화라, 포스터 이미지 인식 성공 여부가 유일한 정답 경로. baseline(gpt-5.4)에서 "확인되지 않는다"로 실패 확인 |

## 🧩 Track 3 — 동적/시멘틱 청킹 검증

**검증 논리**: 한 영화에 대한 논의가 **연속된 여러 분에 걸쳐 흩어져** 있어야 한다. 고정 청킹은 중간에 경계를 끊고, 시멘틱 청킹은 한 덩어리로 유지. **before/after의 retrieval 차이가 선명**하게 나와야 실험 가치 있음.

| # | 질문 | gold 구간 (잘린 영상 기준) | 왜 이 트랙인가 |
| --- | --- | --- | --- |
| C1 | 허키가 스토커(타르코스키)를 선정한 이유와, 그 과정에서 외우라고 한 감독 3명은 누구인가요? | 00:30~01:30 (2분 연속) | 이유 + 감독 리스트(키에슬롭스키 / 조도롭스키 / 타르코스키)가 한 덩어리. 고정 청킹이 자르면 감독 리스트 누락 |
| C2 | 자무시의 '커피와 담배'에 대해 허키가 비판한 두 가지 포인트는 무엇인가요? | 01:30~03:00 | 인맥 자랑 + 섭외력 플렉스 — 두 포인트가 1~2분에 걸쳐 점진적으로 전개 |
| C3 | 노인을 위한 나라는 없다 vs 시계태엽 오렌지를 비교한 결론과 근거는? | 30:00~32:00 | 폭력성 결이 비슷 → 주인공 차이(안식어 vs 경찰)로 반박 → 전환 포인트가 한 덩어리 |
| C4 | 펄프픽션이 4강에서 탈락한 핵심 이유는 무엇인가요? | 33:00~36:00 (3분 연속) | "오염됐다" — 포스터·티셔츠 사는 팬 문화 — 대중화 논의가 장시간 응집 |

**측정 기법**: 같은 질문에 대해 **고정 청킹(현재 30s/5s overlap) vs 시멘틱 청킹**의 `retrieval_precision`을 비교. C1~C4는 모두 "한 영화에 대한 다중 포인트"라서 청킹 경계가 잘못 잡히면 답변이 잘려 나온다.

## 🎚️ Track 4 — Pitch/감정 메타데이터 검증

**검증 논리**: 같은 영화가 **여러 구간에서 언급**되지만, 화자가 **격앙된 구간**에서만 정답이 있다. 화자 ID + pitch 통계가 메타필드로 붙어야 정확한 retrieval이 가능. 없이는 무관한 구간까지 섞여 들어감.

| # | 질문 | gold_answer 힌트 | 왜 이 트랙인가 |
| --- | --- | --- | --- |
| E1 | 김민경이 가장 격렬하게 반대하면서 탈락시키려 한 영화는 무엇이고, 이유는? | 택시 드라이버 — "브라 마이 라이프" 드립, 운전 묘사 과장 비판 (29:00) | 격앙 구간 `pitch_std` 높음. 메타 필터 적용 시 해당 구간만 retrieve |
| E2 | 허키가 가장 단호한 어조로 밀어붙인 결승 우승작과 그때의 표현은? | 노인을 위한 나라는 없다 — "관리갈기 찍겨서 어 그래도 제 리스트에 있던" (37:30) | 화자=허키 + 결승 구간의 특정 pitch 패턴. `speaker_id` 필터 없이는 노이즈 다수 |
| E3 | 누가 펄프픽션을 두고 '심통난다'고 했고, 그 이유는? | 김민경 — 포스터·티셔츠 사는 팬덤, 메인스트림화 (34:00) | '심통'이라는 감정 키워드는 있지만 실제 격앙 구간은 제한적. pitch 메타가 있으면 정확히 해당 발화만 retrieve |
| E4 | 출연자들이 결승전을 두고 '맥빠진다'고 평가한 장면은 언제이고, 누가 말했나요? | 36:00~, 허키가 "결승전이 조금 맥빠지는 느낌" | 화자 분리 + 구간 특정. 비슷한 표현이 다른 구간에 있을 수 있어 pitch/speaker 메타가 결정적 |

**측정 기법**: 동일 질문에 대해 **메타데이터 없이 vs 있이** retrieval 시 `sources`에 잡힌 청크를 비교. E1~E4는 모두 "누가 / 어떤 감정 상태에서" 발화한 **특정 구간**이 정답이라, 메타 필터가 있어야 정답 청크의 similarity ranking이 올라간다.

## 📊 실험 설계

### 한 번에 돌릴 질문셋 구성 (총 12개)

```
V1, V2, V3          (Track 2 - 비전)
C1, C2, C3, C4      (Track 3 - 청킹)
E1, E2, E3, E4      (Track 4 - 메타데이터)
+ H1                (환각 테스트: "영상에서 '기생충'에 대한 언급이 있나요?" → 없음)
```

### 실험 순서

1. **Baseline 측정** — 현재 설정(고정 청킹, 기본 비전, 메타 없음)으로 12개 질문 점수 기록
2. **Track 2 실험** — V1, V2, V3 점수 변동 확인 (비전 모델·프롬프트 교체)
3. **Track 3 실험** — C1~C4 점수만 변동 확인 (시멘틱 청킹 도입)
4. **Track 4 실험** — E1~E4 점수만 변동 확인 (pitch/speaker 메타 추가)

### 냄새 신호

- 한 트랙을 바꿨는데 **다른 트랙 점수가 크게 흔들리면** 실험 격리 실패 → 변수 하나씩 다시 확인
- 환각 테스트(H1)에서 "있다"고 답하면 → groundedness 기반 답변 거부 로직 재확인
- 동일 조건에서 점수가 재현되지 않으면 → LLM 분산 또는 config drift

### 진단

실패 지점은 다음 3가지 중 **①번(비전 모델이 포스터·외형 속성을 묘사하지 않음)** 으로 추정:

1. **비전 프롬프트(v5-code)가 영화 토크쇼에 맞지 않음** — 코드 강의용 프롬프트가 "영화 포스터·출연자 외형"을 추출 대상으로 안내하지 않음. 즉 gpt-5.4에게 필요한 정보를 요구하지 않는 상태였음
2. (가능성 ↓) retrieval이 관련 frame 청크를 못 가져왔을 수 있음 → 별도 확인 필요
3. (가능성 ↓) QA 모델이 프레임 설명을 받고도 과도하게 환각 방지를 적용했을 수 있음 → 가능성 낮음 (설명이 없었다면 "확인 불가"가 정당한 응답)

**핵심 시사점:** gpt-5.4(최강 모델)가 실패했다는 사실은 **모델 크기가 병목이 아니라 프롬프트·메타가 병목**임을 의미. 모델 업그레이드보다 프롬프트·메타 개선이 우선.

### 해석

- **V1, V2는 프롬프트만으로 해결** — baseline 실패의 주 원인이 모델이 아니라 프롬프트 지시 부재였음을 확정.
- **V3는 프롬프트 개선으로 불충분** — 비전이 해당 포스터의 등장 구간 자체를 제대로 묘사하지 못함(A유형).

### V3 A유형 원인 가설

프레임 설명에 "수염", "주황", "선글라스" 관련 서술이 전혀 없는 상태. 가능한 원인:

1. **프레임 샘플링 주기 부족** (현재 `frames_per_minute=1`) — 월드컵 대진표에서 포스터가 스치듯 지나가는 구간을 놓침
2. **월드컵 대진표 뷰에서 개별 포스터가 너무 작음** — 32개 썸네일이 한 화면에 있으면 개별 포스터가 저해상도로 보여 비전 모델이 식별 불가
3. **포스터가 노출된 시점이 짧음** — 대결 도중에만 잠깐 표시되는 영화라 샘플링 타이밍 문제
